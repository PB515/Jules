Role filtering is real, not cosmetic: an Officer's sidebar shows 6 items (no Vault, no Settings — both Owner-only); a Volunteer's shows just Grid Station, scoped to their one assigned event.

A real bug lives in this file's history: the first implementation tried passing pre-built nav items (including Lucide icon components) from the Server Component layout into this Client Component — Next.js throws at runtime since a component reference isn't plain-serializable.
