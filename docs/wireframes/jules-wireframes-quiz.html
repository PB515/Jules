Built with useGSAP(), scoped to the collection-list container ref — glow (opacity/box-shadow tween) → scale-in (transform, springy ease-out) → the locked meta-text crossfades to the unlocked one as the scale settles. No layout shift at any point.

Fires once, on mount, per newly-crossed item — computed the same way as the existing tier-up celebration (compare current lifetime_joules against a localStorage-remembered last-seen value), not on every page load.
