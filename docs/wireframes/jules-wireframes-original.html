Shape: a subtle two-corner cut (clip-path, not a full hexagon) — angular enough to read as "faceted crystal," restrained enough to stay left-aligned and legible at question-answer width. A full hexagon would fight the text.

States map directly onto the existing logic in surge-client.tsx: selected/correct/incorrect/dimmed already exist as separate style branches today (lines 107-109) — this redesign only changes what each branch renders, not the state machine itself. Same true for Live Round's identical option-button pattern.

Built with useGSAP(), scoped to the collection-list container ref — glow (opacity/box-shadow tween) → scale-in (transform, springy ease-out) → the locked meta-text crossfades to the unlocked one as the scale settles. No layout shift at any point — the node and row height never change size, only the glow/scale/text-opacity animate, so nothing jumps around it in the list.

Fires once, on mount, per newly-crossed item — computed the same way as the existing tier-up celebration (compare current lifetime_joules against a localStorage-remembered last-seen value), not on every page load.
